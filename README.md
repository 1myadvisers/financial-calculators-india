# Financial Calculators India

**Free Offline Financial Calculator App for Android**

Financial Calculators India is a free mobile application published by **My Advisers** to help users perform financial calculations conveniently on their Android devices.

The application is designed to provide accessible financial calculation tools with offline functionality.

## Source code

Version **1.1.0** (`versionCode` 2) is the Android Studio project in this repository.

1. Install [Android Studio](https://developer.android.com/studio) on a computer.
2. **File → Open** and select this repository (the folder that contains `settings.gradle.kts`).
3. Let Gradle sync, then press **Run**.
4. For Google Play: **Build → Generate Signed App Bundle / APK**.

Sign a Play update with the same upload key used for the previous release, and keep `versionCode` higher than the live release.

Calculators run from the files in `app/src/main/assets`. Email, WhatsApp, and [myadvisers.in](https://myadvisers.in) open in the phone's own apps.
